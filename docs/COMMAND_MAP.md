# Custom command map

Cypress remains the source of truth (`cypress/support/commands.ts`). Playwright twins live in `playwright/helpers/commands.ts` plus Login/Account page objects. Proof specs: `cypress/e2e/tests/custom-commands.test.ts` and `playwright/e2e/custom-commands.spec.ts`.

| Cypress command                                          | Playwright equivalent                                                                                                                                                                         | Spec that proves it                                                                                        | AUT assertion                                                                                                                                                                                                                                                       |
| -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cy.login(email, password)`                              | `LoginPage.login` (`playwright/pages/LoginPage.ts`)                                                                                                                                           | `custom-commands.test.ts` / `custom-commands.spec.ts` — "login lands on dashboard"                         | URL includes `/dashboard`; `[data-testid=page-title]` contains `Dashboard`                                                                                                                                                                                          |
| `cy.logout()`                                            | `MyAccountPage.logout` + `validateSuccessfulLogout` (`playwright/pages/MyAccountPage.ts`)                                                                                                     | `custom-commands.test.ts` / `custom-commands.spec.ts` — "logout returns to login after login"              | After a real login, URL includes `/login` and `[data-testid=login-container]` is visible                                                                                                                                                                            |
| `cy.getByTestId(id)`                                     | `page.getByTestId(id)`                                                                                                                                                                        | `custom-commands.test.ts` / `custom-commands.spec.ts` — "getByTestId finds the home heading"               | `[data-testid=main-heading]` is visible and contains `Cypress Test Application`                                                                                                                                                                                     |
| `cy.interceptAndWait(method, url, alias, visitPath)`     | `interceptAndWait(page, method, urlSubstring, visitPath)` (`playwright/helpers/commands.ts`)                                                                                                  | `custom-commands.test.ts` / `custom-commands.spec.ts` — "interceptAndWait waits for products on home"      | GET `/api/products` completes (`response.ok()` in Playwright); `[data-testid=product-card]` length `> 0` on `/`                                                                                                                                                     |
| `cy.get(el).typeAndClear(text)`                          | `typeAndClear(locator, text)` (`playwright/helpers/commands.ts`)                                                                                                                              | `custom-commands.test.ts` / `custom-commands.spec.ts` — "typeAndClear types then empties alias-input"      | On `/actions`, `[data-testid=alias-input]` receives the typed value then is empty                                                                                                                                                                                   |
| `cy.get(el).shouldHaveData(attr, value)`                 | `shouldHaveData(locator, attr, value)` (`playwright/helpers/commands.ts`)                                                                                                                     | `custom-commands.test.ts` / `custom-commands.spec.ts` — "shouldHaveData asserts data-field on alias-input" | On `/actions`, `[data-testid=alias-input]` has attribute `data-field="alias"` (not the same attr used to select it)                                                                                                                                                 |
| `cy.get(el).highlight()`                                 | `highlight(locator)` — `locator.evaluate` sets `border: 3px solid red` (`playwright/helpers/commands.ts`)                                                                                     | `custom-commands.test.ts` / `custom-commands.spec.ts` — "highlight sets an inline border"                  | Element `style` attribute includes `border`; computed `border-top-style` is `solid`                                                                                                                                                                                 |
| `cy.setAuthCookie(token)`                                | `setAuthCookie(context, token)` — cookie `{ name: 'authToken', url: 'http://127.0.0.1:3000/', httpOnly: true }` (`path: '/'` inferred; Playwright `addCookies` rejects `url`+`path` together) | `custom-commands.test.ts` / `custom-commands.spec.ts` — "setAuthCookie authenticates GET /api/auth/me"     | `GET /api/auth/me` is `401` without cookie; after `POST /api/auth/login` + `setAuthCookie(body.token)`, `GET /api/auth/me` is `200` and `body.user.email` is `test@example.com`. Playwright uses `page.request` (page context), not the isolated `request` fixture. |
| `cy.fruit(name)` (`Commands.addQuery`)                   | `fruit(page, name)` → `page.locator(".fruit", { hasText: name })`                                                                                                                             | `custom-commands.test.ts` / `custom-commands.spec.ts` — "fruit finds Bananas on /dom"                      | On `/dom`, the locator has `data-testid="item-bananas"` and is visible with text `Bananas`                                                                                                                                                                          |
| `cy.api({ method, url, body })` (`cypress-plugin-api`)   | `request.post(url, { data: body })`                                                                                                                                                           | `custom-commands.test.ts` / `custom-commands.spec.ts` — "api posts a todo"                                 | `POST /api/todos` with `{ title: "cmd" }` returns status `201` and `body.title === "cmd"`                                                                                                                                                                           |
| Overwritten `cy.visit` (logging wrapper around original) | `page.goto` (Playwright has no command overwrite)                                                                                                                                             | `custom-commands.test.ts` / `custom-commands.spec.ts` — "visit still loads home"                           | `/` shows `[data-testid=main-heading]` containing `Cypress Test Application`                                                                                                                                                                                        |

Login and logout are not re-implemented in `playwright/helpers/commands.ts`. Highlight is **not** Cypress-only debug: both specs assert the inline border the helper writes.
