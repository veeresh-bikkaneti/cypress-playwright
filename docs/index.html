veeresh-bikkaneti / cypress-playwright

Setup and use without mixing the two products

This GitHub repo is a Cypress→Playwright migration toolkit for enterprise coding agents and a Cypress-first demo. The application under test is covered by Cypress; Playwright specs are 1:1 migrations of those Cypress specs, not a second independently written suite.

02Why not squash

Create a merge commit on feat PRs

Squash flattens the SDD ledger: portable AGENTS.md, vendor adapters, isolated review, and the Remember-me / storageState fix become one blob. git blame then cannot explain why Playwright must tick Remember me (it does not restore sessionStorage). Dependabot CVE bumps may still squash. Details in CONTRIBUTING.md.

03Setup in your Cypress repo

Install the toolkit, not this demo

Until npm publish, run the CLI from a clone of this repo against your app.

Copy AGENTS.md + skills

Optional --tools copilot,claude,cursor. Grok / Codex / OpenCode need no extra files.

Add Playwright beside Cypress

npm init playwright@latest — do not delete Cypress yet.

Prompt any agent, one spec at a time

Migrate cypress/e2e/login.cy.ts using skills/cypress-to-playwright-migration.

git clone https://github.com/veeresh-bikkaneti/cypress-playwright.git
cd your-cypress-app
node ../cypress-playwright/plugin/bin/setup.js setup --tools copilot,claude,cursor
npm init playwright@latest
# then, in Copilot / Claude / Grok:
# Migrate cypress/e2e/login.cy.ts using the migration skill
